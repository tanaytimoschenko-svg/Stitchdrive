 🚗 StitchDrive — сайт автоателье по перетяжке рулей

Многостраничный адаптивный сайт для автоателье. Разработан с нуля на чистом HTML, CSS и ванильном JavaScript, без JS-фреймворков.

🔗 **Live demo:** https://tanaytimoschenko-svg.github.io/stitchdrive/

 ✨ Ключевые фичи

- 🎨 **Интерактивный выбор материалов** — переключение чипов мгновенно меняет акцентный цвет интерфейса через CSS Custom Properties
- 🚙 **GPU-ускоренные CSS-анимации** — бегущая строка марок, едущая машина, пульсирующий индикатор «онлайн» (только `transform` и `opacity`)
- 🗂️ **Фильтруемая галерея портфолио** — JS-делегирование событий, сопоставление `data-filter` / `data-category`
- 🧊 **Glassmorphism-карточки** — `backdrop-filter: blur` с полупрозрачными фонами
- ♿ **Доступность** — семантическая вёрстка, ARIA-атрибуты, keyboard navigation, `:focus-visible`
- 📱 **Mobile-first адаптивность** — CSS Grid с `auto-fit` и `minmax`, медиа-запросы на 992px и 768px
